# Vicki Bui portfolio

Plain HTML, CSS and JavaScript. No build step. Open `index.html` in VS Code with the Live Server extension, or push the folder to a GitHub Pages repo.

## Files
- `index.html`, `work.html`, `archive.html`, `about.html`, `blog.html`: the five pages.
- `css/style.css`: all styling. Colors are variables at the top (`--cream`, `--ink`, `--brass`, `--red`).
- `js/main.js`: shared masthead, menu and footer (edit nav links and the colophon here), plus the Archive filters.
- `js/data.js`: the Archive list. Add a project by adding one line. **Check the category, skills and tools I guessed.**

## Images (placeholders disappear when a file exists)
`images/work-1.jpg`, `work-2.jpg`, `work-3.jpg` (Work and Home cover), `blog-featured.jpg` (Home and Blog), `blog-1.jpg` to `blog-3.jpg`, `portrait.jpg`, and one per Archive item in `images/archive/` named after the title in lowercase with hyphens (e.g. `digital-twins.jpg`).
